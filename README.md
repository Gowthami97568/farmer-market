# 🌱 Farmer Market App

A modern **React-based e-commerce web application** to buy fresh fruits and vegetables directly from farmers.

---

## 🚀 Features

* 🛒 Add products to cart
* ➕ Increase / ➖ Decrease quantity
* ❌ Remove items from cart
* 💳 Checkout system
* 📦 Place orders
* 📜 View order history
* 👨‍💻 Admin dashboard (orders overview)
* 🧠 Zustand state management
* 💾 LocalStorage persistence (cart & orders saved after refresh)

---

## 🛠 Tech Stack

* ⚛️ React (Vite)
* 🟦 TypeScript
* 🧠 Zustand (State Management)
* 🔀 React Router
* 🎨 CSS / Inline Styling
